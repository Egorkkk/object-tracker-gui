Проект и исходные данные

Для видео FPS берётся из источника. Новый проект создаётся в пустом каталоге; исходники не изменяются.

Mesh · миллиметры

Изменение mesh сбрасывает активные poses; предыдущие raw результаты сохраняются.

Камера

Приближение по ширине полного кадра 36 мм, не калибровка.

Tracked poses архивируются; ручные anchors сохраняются для нового refine.

Маски

Слои отображаются и передаются отдельно. GoTrack baseline не использует маски для refinement.

Diagnostics и экспорт

Пороги отмечают новые suspicious frames; raw poses не меняются.
